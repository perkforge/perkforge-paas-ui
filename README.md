# perkforge-paas-ui

Offline React/TypeScript workspace learning prototype: simulated intent and fixed mock CPU data, with no live model or cluster connection.

See the [learning guide and demo script](docs/LEARNING-GUIDE.md), [proposed architecture decision](docs/ADR-001.md), and [verification notes](docs/VERIFICATION.md).

Node 22.12+: `npm ci`, then `npm run dev` (loopback only). Checks: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
